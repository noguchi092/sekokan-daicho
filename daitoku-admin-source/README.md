# セコカン ダイトク運営管理

契約会社、現場別契約、利用者情報、請求・入金を管理する独立サイトです。

## 公開構成

- GitHub Pagesは入口のみ。`../admin/index.html`からログインサーバーへ移動します。
- 管理画面とAPIはCloudflare Workers互換サーバーで動きます。Pagesだけでは実行できません。
- 現在の確認用サーバーは所有者限定のChatGPT Sitesです。AWSへの移行は未実施です。
- `lib/admin-auth.ts`の許可Originは現在のサーバーに固定されています。移設時は実際のHTTPSドメインに変更し、認証・APIの拒否動作を再検証してください。

## ログイン

初期管理者はサーバーのsecret設定で登録できます（ADMIN_INITIAL_LOGIN / ADMIN_INITIAL_PASSWORD_HASH / ADMIN_INITIAL_PASSWORD_SALT）。パスワードそのものは環境変数にもソースにも保存しません。初期認証の設定がない場合は、所有者認証後に初期設定を行います。ID・パスワードで認証し、8時間有効のセッションを発行します。

初期secretの内容が変わると管理者認証情報を更新し、既存セッションと試行制限を失効させます。招待制の運営アカウント追加は未実装です。

- PBKDF2-SHA256・個別のランダムsaltでパスワードを保存。平文は保存しません。
- セッションはランダム値、DBにはSHA256ダイジェストのみ保存。
- CookieはSecure・HttpOnly・SameSite=Strict。ログアウトでサーバー側セッションも削除。
- 初期設定はプラットフォームの所有者認証が必要。所有者限定の公開設定を維持してください。別のサーバーへ移設するときは、初期設定の所有者認証を同等に置き換える必要があります。
- 15分間に5回の認証試行後は一時制限。Origin検証で外部サイトからの書き込みを拒否。
- 管理画面と記録APIにサーバー側の認証を適用。
- パスワード、顧客データ、セッションはGitHubに保存しません。

## 開発・デプロイ

Node.js 22.13以上。`npm ci`、`npm run db:generate`、`npm run build`。
SQLiteスキーマは`db/schema.ts`、適用済みマイグレーションは`drizzle/`。
D1の論理バインディングはDB。実データはサーバー側で保持します。

## 現状の範囲

利用者は管理台帳で、本体アカウントの発行とは未連携です。請求は記録管理のみで、請求書発行・送信・決済はありません。本体の容量実測・利用停止とも未連携です。
