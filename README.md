# セコカン台帳 v0.2 — 施工管理サイト・スマホアプリ試作版

GitHubでソースを管理し、ロリポップで公開する想定の初期画面です。GitHub Pagesではリポジトリのルートを公開します。ロリポップに配置する場合は `public/` の中身をWeb公開ディレクトリに置きます。HTTPSでアクセスすると、スマホの「ホーム画面に追加」からPWAとして起動できます。

## 試せる機能

- 現場の追加・切り替え
- 工事写真の撮影・登録、工種と撮影場所の記録、検索
- 是正・タスクの登録、期限、担当者、状況変更
- 工程の登録と予定一覧
- ダッシュボード、スマートフォン向け表示

**重要:** 現段階のデータは各端末のブラウザ内（localStorage）に保存します。ログイン、端末間共有、クラウドバックアップ、原本写真の保持はまだありません。実際の現場情報や個人情報を入れず、画面と操作の確認用に使ってください。写真は容量節約のため縮小されます。ブラウザのデータ削除で消える可能性があります。

## ロリポップ公開手順

1. GitHub リポジトリ `noguchi092/sekokan-daicho` の `main` ブランチを更新。
2. ロリポップで公開先の独自ドメインまたはサブドメインと無料SSLを設定。
3. ロリポップで公開する場合は `public/` の中身を公開先ディレクトリへ転送。試作版は GitHub Pages でも公開しています。
4. HTTPSで開き、スマホではブラウザの「ホーム画面に追加」を選択。

GitHubへ置くだけではロリポップに自動反映されません。自動配置は後でGitHub Actions + FTPS/SFTPの構成を追加します。接続情報はGitHub Secretsに保存し、リポジトリへ記載しません。

## 本運用へ進む構成

ロリポップのPHP + MySQLをサーバー側に使い、ユーザー認証、会社・現場ごとの権限、写真原本保存、監査ログ、バックアップを追加します。写真は公開URLから直接閲覧できない領域に保存し、権限確認後に配信します。GitHubはコード管理と配置に使い、業務データの保管先にはしません。

優先実装：①ログイン・会社と現場の権限 ②写真原本・黒板情報・台帳出力 ③是正の担当・期限・前後写真 ④工程・図面・書類 ⑤通知と承認。現場で必要な帳票や権限は本運用前に確認します。

## デザイン

株式会社ダイトクのロゴに見られる、太く斜めに流れる文字の雰囲気を参考にした独立したサービスロゴです。ダイトクの公式ロゴそのものは改変・流用していません。モノトーンを中心に、操作部には視認しやすい青緑を使っています。
