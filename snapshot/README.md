# セコカン台帳のスナップショット

写真指示書機能をセコカン台帳の同じ DOM に直接組み込みました。iframe や別タブへのリンクは使用しません。snapshot/editor.js が台帳内部の部品として動作します。

- 写真管理のフォルダーを指定し、子フォルダーを含む写真から複数選択して読み込む。
- 元画像、または黒板付きの画像をコピーして読み込む。写真管理のデータは変更しない。
- 写真の直接アップロード、PDF図面の追加、写真編集、コメント、写真番号の図面配置、印刷・PDF・Excel出力。
- IndexedDB sekokan-snapshot に現場 ID ごとに作業を保存し、ページを閉じても再開できる。
- 保存できない場合は表示し、再保存を可能にする。保存に失敗したまま別現場への切替を完了させない。

有料版向けの機能として表示しています。現在の本体は端末保存の試作版で、認証・契約・課金による利用制限は未接続です。複数人のオンライン共有は含みません。

- 編集時は台帳の左メニューを畳み、横幅を広く使用できます。
- 元の埋め込み版と同じ保存キーを使うため、既存の写真・図面・指示内容を引き継ぎます。

## 検証

node --experimental-vm-modules tests/snapshot-native.cjs：同一 DOM への組込み、元画面との分離、写真の読込・コメント・PDF 番号配置、編集ダイアログ、破棄、再読込。linkedom と fake-indexeddb が必要です。

node tests/snapshot-storage.cjs：現場別保存、復元、編集情報、PDF 上の番号の参照、保存失敗・再保存、フォルダーの絞り込み。

tests/snapshot-integration.cjs：Playwright による画面・アップロード・出力のテスト。ローカル HTTP サーバー（8765）と Chromium が必要です。今回の実行環境では socket 制限のためブラウザを起動できず、このテストは未実行です。

## 依存ライブラリ

PDF.js は本体の assets/pdf-crop.js を使用します。日本語 CMap と標準フォントは同梱しています。PDF-lib（MIT）と JSZip（MIT / GPLv3）のライセンスは vendor/ に同梱しています。
