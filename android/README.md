# セコカン台帳 Android アプリ（初期版）

Kotlin / Jetpack Compose / CameraX、Android 8.0（API 26）以上。Android Studioでこの `android/` フォルダーをプロジェクトとして開き、SDK 36 と JDK 17 で同期して実機で実行してください。GitHub Actions の **Android APK** でもデバッグ APK をビルドできます。

## 操作

1. 現場と写真フォルダーを選ぶ（必要なら追加）。
2. 「黒板新規作成」から記入欄数を選び、工事名・見出し・内容を入力して保存する。
3. 黒板を選ぶ（または「黒板なし」）→「写真を撮影」→カメラ権限を許可する。
4. 全画面プレビューで黒板を指で動かして位置を決める。黒板は写真の範囲から外へ移動できません。シャッターを押すと、その位置で黒板を合成した JPEG と元の JPEG がアプリ専用領域に別々に保存され、写真一覧に表示される。

黒板は現場ごとに作成します。撮影後の写真は選択したフォルダーにひも付けられます。アプリの削除や端末のデータ消去でファイルが消えるため、業務利用前にサーバー側の認証・同期・バックアップ・写真の書き出しを実装してください。現在、GitHub Pages の Web 版（ブラウザの localStorage）とはデータを共有していません。Android 版の黒板レイアウトは最初の 5 種類です。Web 版の 50 種類以上のレイアウト、豆図、台帳出力などは未移植です。

配布用署名・Google Play 公開設定はまだありません。GitHub Actions の成果物は試用向けデバッグ APK です。
